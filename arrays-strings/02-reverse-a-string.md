# Reverse a String

## Problem
Write a function that reverses a string in-place.

## LeetCode Link
https://leetcode.com/problems/reverse-string/

## Approach
Use two pointers, one at the beginning and one at the end of the string.
Swap the characters and move both pointers toward the center.

## Complexity
- Time Complexity: O(n)
- Space Complexity: O(1)

## Test Case 1
Input:
hello

Output:
olleh

## Test Case 2
Input:
a

Output:
a
